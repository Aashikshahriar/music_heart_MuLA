Tag categories (from the HeartMuLa paper, Sec. 3.2 / Table 6)

These 8 fields are the model's real trained tag categories, listed here in order of training selection probability (impact): Genre .95, Timbre .5, Gender .375, Mood .325, Instrument .25, Scene .2, Region .125, Topic .1. All get folded into one tags string by the backend before hitting the model.
